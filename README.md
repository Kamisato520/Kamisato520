### 🔬 代表性研究 Featured Research: DataEvolver

<div align="center">
  <h3><a href="https://github.com/PRIS-CV/DataEvolver">DataEvolver: Let Your Data Build and Improve Itself via Goal-Driven Loop Agents</a></h3>

  <p>
    <a href="https://arxiv.org/abs/2605.01789"><img src="https://img.shields.io/badge/Paper-arXiv%3A2605.01789-b31b1b?style=flat-square&logo=arxiv&logoColor=white" alt="arXiv"></a>
    <a href="https://github.com/PRIS-CV/DataEvolver"><img src="https://img.shields.io/badge/Code-PRIS--CV%2FDataEvolver-blue?style=flat-square&logo=github&logoColor=white" alt="Code"></a>
    <a href="https://pris-cv.github.io/DataEvolver/"><img src="https://img.shields.io/badge/Project-Page-0078D7?style=flat-square&logo=googlechrome&logoColor=white" alt="Project Page"></a>
    <a href="https://kamisato520.github.io/files/method_overview.pdf"><img src="https://img.shields.io/badge/Method-Overview-9cf?style=flat-square" alt="Method Overview"></a>
  </p>
</div>

* **角色 Role**：第一作者（共同一作）· 核心研发 — *First author (equal contribution) · Core R&amp;D*
* **核心思想 Core Idea**：DataEvolver 将可控视觉数据构建转化为可记录的反馈闭环——候选生成与 VLM/CV 质检门控构成内循环，下游弱模型行为转化为定向训练数据补充构成外循环。 *Turns controllable visual data construction into recorded feedback loops: candidate generation with VLM/CV quality gates (inner loop), downstream weak-model behavior into targeted training data additions (outer loop).*
* **关键成果 Key Results**：
  * 🎤 **Oral 报告 Oral Presentation** — AIDataSci 2026 (KDD 2026 Workshop)
  * 📜 **海报展示 Poster Presentation** — 2026 BAAI 大会 Agent for Science 竞赛
  * 📊 **下游效果 Downstream Impact**：在 SpatialEdit 的 488 个图像级物体旋转样本上达到 **16.79 PSNR**、**0.9525 CLIP-I**、**0.8918 DINO**，较 Public LoRA 提升 **+1.03 dB PSNR**。 *16.79 PSNR / 0.9525 CLIP-I / 0.8918 DINO on 488 image-level rotation samples of SpatialEdit (+1.03 dB PSNR over Public LoRA).*

### 🚀 项目 Projects

* **[DataEvolver](https://github.com/PRIS-CV/DataEvolver) — 目标驱动的闭环视觉数据自演化引擎 Goal-Driven Synthetic Visual Data Engine**  
  VLM + Agent 闭环渲染：24 有界动作空间、内层质量门控与下游反馈外循环，将弱视角转化为定向数据扩增。 *24-action VLM+Agent rendering loop with inner quality gates and an outer downstream feedback loop.*（[方法图 method](https://kamisato520.github.io/files/method_overview.pdf) · [自演化 evolution](https://kamisato520.github.io/files/dataevolver_self_evolution.pdf) · [对比 comparison](https://kamisato520.github.io/files/dataevolver_rotation_comparison.pdf)）
* **多任务图像编辑 LoRA 微调系统 Multi-task Image Editing LoRA System**  
  基于 30B Qwen-Image-Edit 微调旋转、移动、插入与消除任务；训练 11 个视角特定 LoRA（30°–180°），Preset LoRA 课程学习 + Additive Rehearsal 抗遗忘。 *Rotation / movement / insertion / removal on 30B Qwen-Image-Edit; 11 angle-specific LoRAs with Preset-LoRA curriculum &amp; additive rehearsal.*
* **YouAI — 自演化多模态 UI 智能体 Self-Evolving Multimodal UI Agent**  
  基于 Mobile-Agent-E 的 Manager/Operator 架构，加入 Tips/Shortcuts 长期经验记忆；在 Mobile-Eval-E 上达到 86.9% 满意度、90.4% 动作准确率。 *Manager/Operator architecture with persistent Tips/Shortcuts memory; 86.9% satisfaction &amp; 90.4% action accuracy on Mobile-Eval-E.*
* **研究生教育质量评估助手 Graduate Education Assessment Assistant**  
  LLM 辅助主客观协同评分（正确性、逻辑性、表达）+ ChromaDB RAG 检索。 *LLM-assisted subjective scoring (correctness, logic, expression) with human-in-the-loop review &amp; ChromaDB RAG.*
