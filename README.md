### 🔬 Featured Research: DataEvolver

<div align="center">
  <h3><a href="https://github.com/PRIS-CV/DataEvolver">DataEvolver: Let Your Data Build and Improve Itself via Goal-Driven Loop Agents</a></h3>

  <p>
    <a href="https://arxiv.org/abs/2605.01789"><img src="https://img.shields.io/badge/Paper-arXiv%3A2605.01789-b31b1b?style=flat-square&logo=arxiv&logoColor=white" alt="arXiv"></a>
    <a href="https://github.com/PRIS-CV/DataEvolver"><img src="https://img.shields.io/badge/Code-PRIS--CV%2FDataEvolver-blue?style=flat-square&logo=github&logoColor=white" alt="Code"></a>
    <a href="https://pris-cv.github.io/DataEvolver/"><img src="https://img.shields.io/badge/Project-Page-0078D7?style=flat-square&logo=googlechrome&logoColor=white" alt="Project Page"></a>
  </p>
</div>

* **Role**: First author (equal contribution), core R&D, project lead.
* **Core Idea**: DataEvolver turns controllable visual data construction into recorded feedback loops. It links candidate generation with VLM/CV quality gates (inner loop) and converts downstream weak-model behavior into targeted training data additions (outer loop).
* **Key Achievements**:
  * 🎤 **Oral Presentation** @ AIDataSci 2026 (KDD 2026 Workshop)
  * 📜 **Poster Presentation** @ 2026 BAAI Conference Agent for Science Competition
  * 📊 **Downstream Impact**: Reached **16.79 PSNR**, **0.9525 CLIP-I**, and **0.8918 DINO** on SpatialEdit (outperforming Public LoRA by **+1.03 dB PSNR** and **+0.0625 CLIP-I**).
